# VaperKing - Sistema de Gestión para Tiendas de Vapeo

Sistema completo de gestión comercial para tiendas de vapeo, incluyendo ventas, inventario, reportes y administración de múltiples sedes.

## 🚀 Características

- 📊 Dashboard interactivo con métricas en tiempo real
- 💰 Gestión de ventas con múltiples métodos de pago
- 📦 Control de inventario por sede
- 👥 Gestión de usuarios y roles (Admin/Vendedor)
- 🏢 Administración de múltiples sedes
- 📈 Reportes y estadísticas
- 🔐 Autenticación JWT
- 📱 Diseño responsive

## 🛠️ Tecnologías

### Backend
- FastAPI (Python)
- SQLAlchemy ORM
- MySQL
- JWT Authentication
- Pydantic

### Frontend
- React 18
- TypeScript
- Zustand (State Management)
- Vite
- Axios

## 📋 Prerrequisitos

- Python 3.12+
- Node.js 18+
- MySQL 8.0
